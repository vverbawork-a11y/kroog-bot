# Промокоды

Управление доступно владельцу бота в Mini App: **Склад → Промокоды**.
Созданных заранее кодов и назначенной по умолчанию скидки нет.

При создании укажите название кода (3–32 латинские буквы, цифры, дефис или
подчёркивание) и скидку в процентах. Регистр не важен.

Дополнительные ограничения:

- общий лимит использований; пустое поле означает отсутствие общего лимита;
- дата и время окончания в часовом поясе вашего устройства;
- Telegram ID получателя для персонального кода (получатель узнаёт его командой
  `/id` в боте); пустое поле позволяет передавать код любым получателям;
- «Только для повторного заказа»: у пользователя уже должен быть оформленный
  неотменённый заказ в Mini App. Оплата в текущей системе отдельно не учитывается.

Каждый код можно использовать один раз с одного Telegram-аккаунта. На заказ
применяется **только один промокод**. Процент распространяется на сумму заказа
с выбранной печатью и срочностью. Со скидкой за тираж применяется большая из
двух скидок. Если скидка за тираж выгоднее или равна, код не расходуется.

Ввод кода и кнопка «Применить» находятся перед итогом и кнопкой оформления.
Проверка кода показывает сумму, но не резервирует использование. Сервер повторно
проверяет условия при оформлении и в одной транзакции сохраняет заказ,
списывает остаток и учитывает код. Повторная отправка того же заказа не
расходует код повторно. Нельзя изменить скидку через поля клиентского запроса.

Владелец может отключить или снова включить код. Отключение не меняет суммы
ранее принятых заказов. При отмене заказа владельцем использование возвращается,
а история заказа сохраняет исходную цену и применённый код.

Для закрытого тестирования создайте код после выбора размера скидки и
передайте его друзьям. Для праздника можно задать срок и общий лимит;
для извинения — конкретного получателя и лимит 1. Само по себе знание
общего кода не подтверждает принадлежность к кругу друзей; для строгого
ограничения используйте персональные коды с Telegram ID.
