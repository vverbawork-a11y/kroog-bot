# Деплой на Bothost.ru (через GitHub)

## Тариф
Нужен **платный** тариф (минимум Basic, 99 ₽/мес) — на бесплатном данные стираются,
а у нас склад хранится в базе. Платный даёт постоянную папку `data`.

## Репозиторий
`vverbawork-a11y/kroog-bot` (приватный), ветка `main`.

## Команда запуска
```
python main.py
```
(в проекте есть Procfile: `worker: python main.py`)

## Переменные окружения (Environment Variables)
Задаются в панели Bothost — НЕ в коде:

Реальные значения НЕ храним в репозитории — они в config_local.py (локально)
и в панели Bothost. Здесь только список переменных:

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather |
| `ADMIN_ID` | твой Telegram ID (куда приходят заявки) |
| `MANAGER_USERNAME` | username менеджера без @ |
| `CHANNEL_URL` | ссылка-приглашение на Telegram-канал |
| `DB_PATH` | data/kroog.db |

## Постоянное хранилище
База лежит в `data/kroog.db`. Папка `data` на Bothost сохраняется между
перезапусками и обновлениями — остатки склада не сбрасываются.

## Важно
Одновременно должна работать только ОДНА копия бота. Когда бот поднят на Bothost —
останови копию на Маке (закрой окно run.command или `pkill -f main.py`),
иначе будет ошибка Telegram «Conflict».
